# 轻忆 · SillyTavern-LightMemory

面向长篇角色扮演的 SillyTavern 前端记忆扩展：按可调预算保留近期对话，分批整理旧内容，再按当前对话召回相关记忆。

**当前为 0.1.1 开发快照，尚未完成完整验收。** 开发基准为 SillyTavern 1.19.0、提交 `06bde939f`。请先在测试聊天中验证；详细进度见 [验证记录](TESTING.md)。

## 当前实现

- 近期上下文、最低回合数、整理阈值、摘要批次和注入预算可调。
- 记忆采集复用宿主上下文正则；正文预览用于检查实际采集结果，不采集独立 reasoning 字段。
- 分批摘要、历史概览、人物及别名、关系、物品、约定、伏笔和状态记录。
- 本地中文关键词召回；可选语义向量与关键词合并召回，服务失败时回退本地检索。
- 摘要连接可沿用主 API，或选择独立 OpenAI 兼容 API；独立密钥通过宿主管理，扩展保存密钥 ID。
- 每个聊天独立保存记忆及来源指纹，支持查看、编辑、固定、排除、导入和导出。
- 保留聊天存档原文，仅在生成请求中省略已整理且通过保存读回校验的旧内容。

这些是当前代码实现范围，不代表所有宿主、模型及服务组合均已实测通过。

## 安装与开始使用

在酒馆“扩展 → 安装扩展”中输入本仓库地址：

```text
https://github.com/demilich1117/SillyTavern-LightMemory
```

也可以在酒馆根目录执行：

```sh
git clone https://github.com/demilich1117/SillyTavern-LightMemory.git public/scripts/extensions/third-party/SillyTavern-LightMemory
```

也可下载仓库 ZIP，将包含 `manifest.json` 的目录放到对应的 `third-party` 目录。

刷新酒馆，在扩展设置打开“轻忆 · LightMemory”。先打开一个测试聊天，选择摘要连接，点击“测试摘要连接”。通过后再启用轻忆。默认不开启自动接管，启用轻忆后按“自动整理”设置执行。

独立 API 使用 Base URL、模型名和酒馆 Custom（OpenAI-compatible）密钥 ID。扩展不提供明文密钥输入框。主 API 首版代码适配 Chat Completion 与 Text Completion；其他类型可使用独立连接。

## 默认预算

| 参数 | 默认值 |
|---|---:|
| 近期上下文目标 | 12,000 tokens |
| 最低保留完整回合 | 4 轮 |
| 窗口外待整理文本阈值 | 4,000 tokens |
| 窗口外待整理回合阈值 | 8 轮 |
| 单批摘要输入目标 / 上限 | 4,000 / 6,000 tokens |
| 记忆注入预算 | 2,000 tokens |
| 最多召回条数 | 6 条 |

一次用户输入及随后角色回复算一轮；群聊同轮可包含多个角色回复。窗口外尚未整理的内容达到文本量或回合数任一阈值，即可触发整理。未完成整理与保存确认的正文继续交给酒馆处理。

近期目标只计算聊天内容，不包括预设、角色卡、世界书、其他扩展或长期记忆。宿主动态世界书等开销目前使用保守估算，酒馆执行最终上下文限制；最低回合数是软保护。实际窗口会随文本 token 数变化，不承诺固定保留多少条消息。

未知的独立模型或嵌入分词器采用保守估算，实际摘要输入还受 API 上下文和输出预留限制。向量服务首版接入 Transformers、OpenAI、硅基流动和 Ollama；切换模型或端点后应重建索引。

### 摘要输出被截断

0.1.1 起，收到 `finish_reason: length` 等输出上限标记时，会明确提示“摘要输出达到上限”，不会尝试补齐 JSON 或用独立思考内容替代正文。完整的 Markdown JSON 代码块仍可解析。

摘要输出预留的新默认值为 4,096 tokens；已有配置不会被覆盖。部分思考模型会将思考与最终 JSON 计入同一输出额度。遇到截断时，可在高级设置将输出预留调到 4,096 或 8,192；同时保证摘要上下文额度足够，实际输出预留最多为有效上下文的一半。提高输出预留会减少单批可用输入，插件会据此重新规划后续批次。必要时也可在服务商支持的配置中降低思考强度。

失败批次不会推进进度，调整参数后可以再次“整理历史”。扩展不会自动反复扩大额度重试。

## 数据与请求

全局配置存入扩展设置，记忆存入聊天元数据。摘要会发送清理后的正文与历史概览至所选摘要服务；向量模式会将清理后的正文块发送至所选嵌入服务。本地关键词召回无需额外调用模型，但生成摘要仍需要摘要 API。

编辑、删除、swipe 或正则清理结果变化后，受影响记忆会失效，相关原文恢复保留。请通过“采集预览”确认预设中的思考、状态栏等内容确实被上下文正则排除。其他记忆扩展可能重复注入，轻忆不会自动修改它们的配置。

## 开发

原生 ES modules，无构建步骤或第三方运行时依赖。开发检查需要 Node.js 20 或更高版本：

```sh
npm test
npm run check
```

`src/core.js` 负责预算与记忆纯逻辑，`host.js` 隔离宿主接口，`engine.js` 调度任务，`vectors.js` 负责索引与语义召回，`ui.js` 提供中文面板。

当前仓库未指定开源许可证；上传开发快照不代表授予开源许可。后续正式发布时再明确许可证。
